**Architecture clés** :
- Capture-phase `click` listener (intercepte avant handlers user)
- `delay === 0` → filtering désactivé (all clicks pass)
- `dblclick` non intercepté (event path séparé)
- `blockedCount` dans state (monitoring sans telemetry)
- AbortController teardown (pattern B-103)
- Storage sous-clé `clickDelay` sous `MORPHIC_STORAGE_KEY`
- Defensive: TypeError (non-number) + RangeError (hors [0,500]) + validateClickDelay pure guard
