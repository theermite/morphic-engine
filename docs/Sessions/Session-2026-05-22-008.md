## Décisions / Deviations

| Décision | Raison |
|----------|--------|
| `enableCommandPalette({ commands })` au lieu de `registerShortcut(key, action)` individuel | Palette = collection de commands, pas raccourci isolé. L'API match l'intention F-029 ("⌘K pour ouvrir une palette") plutôt qu'un registry global de keybindings. |
| `Mod` token résolu at match time | Une seule représentation ParsedCombo pour tous les OS — pas de duplication mémoire ni re-parse. Match-time check : `combo.mod ? (os === 'mac' ? event.metaKey : event.ctrlKey) : ...` |
| Substring fallback avant Fuse loaded | Fuzzy search nice-to-have, mais palette doit être utilisable dès la 1ère frappe — ne pas attendre le chunk. |
| `executeCommand` try/catch silencieux | Bug dans `cmd.action()` (host) ne doit pas casser le listener global. Counted nowhere (pas de telemetry interne), à charge du host de logger. |
| Custom event `morphic-execute` sur mousedown | mousedown plutôt que click pour réagir avant la propagation focus loss (pattern command-k UX). |
| Pas de PBT mutation testing (Standard 80%) | CDC §7 classifie F-029 Standard. Pas de mutation requise. 2 PBT properties sont du bonus (round-trip + ctrl flip). |
