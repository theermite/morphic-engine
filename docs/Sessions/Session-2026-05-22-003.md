### Couplage Ki — Architecture unidirectionnelle (D4)

```
Engine API publique (consommée par apps Shinkofa) :
  setEnergyProfile(profile), getEnergyProfile()
  enterRecoveryMode(), exitRecoveryMode()

Engine émet (events) :
  morphic:energy:change
  morphic:energy:recovery-enter / recovery-exit
  morphic:energy:pause-suggested
  morphic:energy:pomodoro-tick
  morphic:energy:pomodoro-break-start
  morphic:energy:pomodoro-work-resume
  morphic:energy:pomodoro-session-complete
```

Apps Shinkofa (Shizen, Niwa, Hibiki, Koshin) consomment → l'engine reste **framework-agnostic, zéro dépendance sortante vers Shinkofa-Shared**. La FAB Shinkofa.com = consumer du moteur Pomodoro F-035.
