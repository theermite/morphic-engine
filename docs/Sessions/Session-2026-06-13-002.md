### Correctif tarball wasm-core (défaut attrapé au `--dry-run`)
- **Symptôme** : 1er dry-run = 5 fichiers, **binaire `.wasm` ABSENT** + `.d.ts` absents. Paquet aurait été mort à l'install.
- **Cause racine** : `wasm-pack` génère `pkg/.gitignore` contenant `*`. npm respecte ce `.gitignore` et exclut tout `pkg/` sauf le `main` (`.js`) et le README (toujours inclus). Le `.wasm` (le vrai code) et les types sautaient.
- **Fix durable** :
  - Build script : `&& rm -f pkg/.gitignore` (sinon `wasm-pack` le régénère à chaque build).
  - Racine `.gitignore` : `packages/wasm-core/pkg/` (npm ne lit pas le `.gitignore` racine quand il empaquète le sous-paquet → le `.wasm` est inclus ; git continue d'ignorer `pkg/`).
- **Preuve** : 2e dry-run = 9 fichiers, `pkg/morphic_wasm_core_bg.wasm` 58.8 kB présent + `.d.ts` + LICENSE. `git check-ignore` confirme pkg toujours ignoré.
