|----------|-------------|-----|
| Density/Font-Size/Contrast/Motion invisibles | CSS demo utilise `[data-morphic-X]` attributs mais engine pose des CSS vars `--morphic-X` | Ajouté `syncVarsToAttrs()` qui mirror les vars vers les attributs après chaque set |

| CVD subtil | Daltonisation CORRECTIVE (Fidaner 2005), pas simulation | Ajouté 6 swatches couleur pour rendre le shift observable |
