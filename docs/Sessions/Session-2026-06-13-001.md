Renommage laissé à moitié + scopes contradictoires. Le moteur avait été renommé
`@morphic/engine → @theermite/morphic-engine` (commits `4bfa9ac` 2026-05-25 puis

code interne se décrivait sous **trois** scopes : `@morphic/engine`,
`@theermite/morphic-engine`, `@shinkofa/morphic-engine`.

**Bombe à retardement (latent break)** : `packages/adapter` importait `@morphic/engine`
(nom que le moteur n'exposait plus). Résolution uniquement via un symlink périmé
`node_modules/@morphic/engine` créé le 2026-05-23 avant le renommage. Un
`pnpm install` propre aurait supprimé ce lien → build adapter cassé.

**Preuves publiques (NLNet + article)** : nom produit `morphic-engine` + repo
`github.com/theermite/morphic-engine` cohérents partout. Le scope npm était la
seule incohérence. Décision Jay : unifier sur **`@theermite/*`** (colle au repo,
= décision de renommage déjà prise deux fois, antérieure au dépôt NLNet du 27/05).
