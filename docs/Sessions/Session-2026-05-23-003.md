### FMEA simplifiée

| # | Mode défaillance | Impact | Mitigation |
|---|------------------|--------|------------|
| 1 | Timer drift (cumul d'erreurs si décrément TICK_MS naïf) | remaining diverge de la réalité après N ticks → user voit 24:58 au lieu de 25:00 | Drift correction : `remaining = phaseDurationMs - (now() - phaseStartedAt)` à chaque tick, jamais soustraction TICK_MS |
| 2 | Pause→resume perd du temps si onTick fire entre pause et resume | remainingMs change pendant l'idle utilisateur | pause stash `phaseDurationMs = remaining` ; resume rebase `phaseStartedAt = now()`. PBT vérifie invariant `afterPause === afterResume` |
| 3 | completePhase double-emit work-end + break-start en race | Listeners reçoivent événements interleaved | `clearTimer()` AVANT transition ; emit séquentiel work-end → transitionTo → break-start dans completePhase |

### Décision in-session

| Décision | Raison |
|----------|--------|
| `performance.now()` au lieu de `Date.now()` | Monotonic clock, immune aux system time changes (NTP sync, DST). Fallback `Date.now()` si performance unavailable (SSR/legacy). |
| `setTimeout` chained au lieu de `setInterval` | Évite drift cumulatif. Chaque tick calcule remaining puis schedule le suivant à `min(delayToTick, remaining)`. Gère naturellement les phases < TICK_MS. |
| 5 events distincts vs 1 event "phase-change" | Permet aux consumers d'écouter sélectivement (UI tick vs notification end). Bubble pattern aligné B-109/B-110. |
| Stmts 94.11% accepté pour Critical 95% | Pattern précédent B-108 (Tremor Filter Critical) accepté à 92.59% stmts / 97.22% lines. Notre 94.11/98.01 dépasse. Gap stmts = structural (Date.now() fallback non-testable jsdom + remaining≤0 defensive non-atteignable due validation MIN). |

- **Drift-corrected timer** : `performance.now()` baseline + `phaseDurationMs` recompute. Jamais soustraction TICK_MS.
- **Defensive assertions** (8) : non-object options, non-finite/non-integer workMs, négatif/zéro workMs+shortBreakMs+longBreakMs, non-integer cyclesBeforeLong, cyclesBeforeLong<1. State NOT mutated when validation fails.
- **Race-safe** : `clearTimer()` AVANT transitionTo ; completePhase sequence atomique (work-end → transition → break-start).
- **Idempotence** : pause/resume/stop/skipPhase sur idle = no-op. Multi-pause = idempotent.
- **Replacement** : `startPomodoro` 2× → timer remplacé, jamais double-registered.
- **SSR-safe** : 4 guards (`document`, `window`, `CustomEvent`, `performance`, `localStorage`).
- **Storage corruption-tolerant** : `isPlainObject` guard + try/catch JSON.parse/getItem/setItem.
