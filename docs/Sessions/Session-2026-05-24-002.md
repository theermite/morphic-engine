## Travail realise

### B-021g Phase 1 — setTarget API (morphic-engine)

**Probleme** : Jay rapporte regression logos/icones site — MorphicLab.css utilise `html[data-morphic-*]` selecteurs qui cascadent globalement, pas seulement dans `/lab/morphic`. Les axes engine ecrivent exclusivement sur `document.documentElement`, sans possibilite de scope.

**Solution** : nouveau module `target.ts` avec API :
- `setTarget(element: HTMLElement | null): void` — null = reset au defaut
- `getTarget(): HTMLElement` — retourne `document.documentElement` par defaut
- `__resetTargetForTests(): void` — reset pour isolation test

**Refactoring 6 axes** : theme, contrast, density, motion, typography, font-family — tous remplaces `document.documentElement` par `getTarget()` pour les operations DOM (setAttribute + setProperty).

**Contraintes preservees** :
- `init.ts` (head-read synchrone) reste hardcode sur `document.documentElement` — tourne AVANT tout JS utilisateur
- Backward compat stricte — si `setTarget()` jamais appele, comportement identique
- Caveat documente : `rem` ne fonctionne pas en scope element (browser lie `rem` a `<html>` uniquement)

**Fichiers modifies** :
- `src/target.ts` (nouveau)
- `tests/target.test.ts` (nouveau, 16 tests)
- `src/theme.ts`, `src/contrast.ts`, `src/density.ts`, `src/motion.ts`, `src/typography.ts`, `src/font-family.ts` — import `getTarget` + remplacement `document.documentElement`
- `src/index.ts` — export `setTarget`, `getTarget`, `__resetTargetForTests` + VERSION bump `2.0.0-beta.2`
- `tests/smoke.test.ts` — align assertion sur `2.0.0-beta.2`
- `package.json` — version `2.0.0-beta.1` → `2.0.0-beta.2`

## Decisions

- **`HTMLElement` pas `Element`** : `getTarget()` retourne `HTMLElement` car les axes utilisent `.style.setProperty()` qui est HTMLElement-only. Les SVGElement ne sont pas un use case pour le Lab.
- **`init.ts` reste hardcode** : head-read synchrone, execute avant tout JS utilisateur — impossible d'appeler `setTarget` avant. Decision B-021g validee par Jay.
- **Phase 2 en session separee** : session fraiche pour le deploy Docker prod The-Ermite (risque reduit).
- **Stale files pre-existants** : adapter/package.json, pnpm-lock, LICENSE, .npmrc, README — non commites, traitement differe (scope B-026 original).
