## 4. Décisions

1. **DataStore injecté** (A-3) → testabilité pure JVM, pas d'émulateur.
2. **Robolectric différé** (A-4) → Composable fin validé en app réelle, pas en CI.
3. **compileSdk 35 → 36** → requis par Compose 1.10.x (Android 16). A-0 avait flaggé ce pin pour revue.
4. **Parité headless** → le module Android expose les axes résolus, n'impose pas de tailles (comme le web).
5. **Versions figées à la brique qui les introduit**, pas toutes à A-0 (PET §5 corrigé).
