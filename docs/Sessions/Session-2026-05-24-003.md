## Decisions

- **Re-application apres setTarget** : on mount, re-lire l'etat via les getters puis re-appliquer via les setters. Sans cela, la nouvelle cible (preview div) demarre sans aucun attribut `data-morphic-*` malgre un etat present dans localStorage. Pattern documente.
- **Caveat `rem`** assume : le scope element ne peut pas redefinir `rem` (browser-bound a `<html>`). Tailwind text-* (rem) suit donc la racine du site. Accepte tel quel — pas de regression visible sur Lab, et la solution alternative (forcer `em` partout dans le preview) casserait l'integration drop-in du Lab.
- **B-021d (SSR custom elements)** reste pending — separe car nature differente (engine-side guard, pas consumer wiring). Sera traite dans une session dediee.
