Module `cognitive.ts` — API runtime pour configurer et valider le cap de decision points par écran morphique (BLOCKING Dignity §a Cognitive Load).

- `MORPHIC_DECISION_POINTS_CAP_DEFAULT = 3` (ceiling Dignity §a)
- `MORPHIC_DECISION_POINTS_CAP_MAX = 20` (DoS guard)
- `setDecisionPointsCap(cap)` : valide + persiste localStorage + in-memory cache
- `getDecisionPointsCap()` : mémoire → localStorage → DEFAULT
- `validateDecisionPoints(count)` : retourne `count <= cap`, throw sur input invalide
