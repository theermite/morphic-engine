## Objectif

Implémenter B-103 Reading Guide — 3 modes d'aide visuelle à la lecture (`line`, `mask`, `ruler`) avec runtime API `setReadingGuide()` + persistance localStorage + respect `prefers-reduced-motion`. Coverage cible Sensitive 90%.

## Travail réalisé

### Recherche / Veille

- IntersectionObserver écarté après analyse : resolution trop coarse pour cursor tracking (fire sur visibility d'éléments, pas position curseur).
- Pattern A retenu : single full-viewport `position: fixed` div avec `clip-path: polygon(...)` cutting hole pour reading band — perf > N overlays empilés.
- AbortController validé pour cleanup mousemove listeners (single signal abort tout).
- WCAG 2.3.3 (Animation from Interactions) : cursor tracking essentiel donc préservé sous `prefers-reduced-motion: reduce` — seul l'easing transition est strippé.
- `pointer-events: none` non-négociable sur tous les overlays (page reste interactive).
