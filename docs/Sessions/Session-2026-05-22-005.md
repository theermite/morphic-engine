## Décisions techniques

| Aspect | Décision | Justification |
|--------|----------|---------------|
| Escape order | **Tokenize-then-escape** (regex `\p{L}+/gu` segmente, escapeHtml par segment) | Première impl escape-then-tokenize → letter-bleed bug : regex `\p{L}+` matchait les lettres INSIDE `&amp;` → `<b>a</b>&<b>am</b>p;<b>b</b>`. Fix : segmenter texte brut FIRST, puis escape chaque segment. |
| Idempotence | **Marker `data-morphic-reading-focus`** sur chaque `<b>` créé | `clearReadingFocus` unwrap seulement nos `<b>` (préserve les `<b>` utilisateur). `setReadingFocus` re-appelable sans accumulation. |
| Scope DOM | TreeWalker SHOW_TEXT, skip `SCRIPT/STYLE/NOSCRIPT/TEXTAREA/INPUT/CODE/PRE` | Ne casse pas le code (PRE/CODE), n'altère pas les valeurs de formulaire, ne s'exécute pas dans SCRIPT/STYLE |
| Cible | `<main>`, `<article>`, ou `[data-morphic-reading-focus]` (default `<main>`) | Préserve nav/UI/aside — Reading Focus = contenu de lecture, pas l'interface |
| Persistance | Sous-clé `readingFocus` dans `MORPHIC_STORAGE_KEY` | Cohérent avec colorVision (B-101) et autres axes futurs |
| Default | **OFF** | Evidence scientifique mixte 2022-2025 ; opt-in user explicite obligatoire |
