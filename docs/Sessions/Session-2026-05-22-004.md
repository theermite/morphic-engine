## Algorithme — décision technique

| Aspect | Décision | Justification |
|--------|----------|---------------|
| Simulation CVD | **Machado-Oliveira 2009** (au lieu de Viénot 1999 initialement planifié) | Viénot protan : row 0 somme à -0.50237 → ne préserve PAS l'axe grayscale. Machado-Oliveira : toutes lignes somment à 1.0 → invariant requis pour que M_dalt préserve les gris. |
| Correction | **Fidaner 2005 LMS-shift** | Mode mathématique stable + différentiable, compatible feColorMatrix linéaire. Brettel 1997 = simulation, pas correction. |
| Matrice de shift | **Unifiée** `[0,0,0; 0.7,1,0; 0.7,0,1]` pour les 3 CVD | Row 0 = [0,0,0] → garantit M_dalt[0] = identité (1,0,0). PBT "preserves identity row" uniforme. |
| Espace couleur | **Linéarisation sRGB obligatoire** + `color-interpolation-filters="linearRGB"` sur SVG | IEC 61966-2-1 ; sans linéarisation, distorsion gamma 2.4 visible |

Cette divergence vs PET initial (Brettel/Viénot) est documentée dans le commit message PET 0ebf3e1.
