# Documentation

This folder holds the design and the development record of morphic-engine. The
project is developed in French and published in English: the package READMEs and the
root README are in English, most documents below are in French.

| Document | What it is | Language |
|---|---|---|
| [`CDC.md`](CDC.md) | Specification (*cahier des charges*): intent, features, risk classification, quality gates | French |
| [`PET.md`](PET.md) | Execution plan and roadmap of the web packages, brick by brick | French |
| [`PET-Android.md`](PET-Android.md) | Execution plan of the native Android port | French |
| [`Changelog-v1-v2.md`](Changelog-v1-v2.md) | What changed between the first engine (coupled to React) and this rewrite | French |
| [`Presentation.html`](Presentation.html) | One-page visual presentation of the project | French |
| [`audits/`](audits) | Dated quality audits, including the go / no-go review of 2026-05-28 | French |
| [`veille/`](veille) | Technology and competitor watch: existing accessibility tools compared | French |
| [`Articles/`](Articles) | Published articles: why accessibility overlays fail, and what morphic adaptation does instead | French |
| [`Sessions/`](Sessions) | Development journal: one report per working session since 2026-05-21 — what was done, what failed and why, what was decided | French |

The session journal is kept public on purpose: it shows how the engine was built,
including the mistakes and how they were corrected.
